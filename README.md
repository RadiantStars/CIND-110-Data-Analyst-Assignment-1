# CIND 110: Data Organization for Data Analysts — Assignment 1

This repository contains the solution for **Assignment 1** of the CIND 110 course (Data Organization for Data Analysts). The primary objective of this assignment is to apply foundational database management and design principles to a structured business or organizational scenario.

## 📌 Project Overview
The assignment focuses on the conceptual and logical design phases of building a relational database system. It demonstrates how to translate real-world data requirements into an organized, normalized database structure that ensures data integrity.

## 🛠️ Key Topics Covered
* **Requirement Analysis:** Extracting business rules, entities, and attributes from a provided case study.
* **Entity-Relationship Diagram (ERD):** Creating a visual representation of the database schema, detailing entities, primary/foreign keys, attributes, and relationships (with proper cardinality).
* **Logical Database Design:** Forward engineering the ERD into a set of relational schemas.
* **Data Normalization:** Ensuring the tables satisfy First, Second, and Third Normal Forms (1NF, 2NF, 3NF) to minimize data redundancy.

## 📂 Repository Structure
* `/docs` or Root: Contains the final assignment report (`.pdf` or `.docx`).
* `/diagrams`: Contains the visual entity-relationship diagrams (ERDs) created using tools like MySQL Workbench.
* `README.md`: Project overview and setup instructions.
